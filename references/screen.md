阶段零：找项目与健康度自检清单（前置筛查）
在把仓库喂给 AI 之前，先用这套通用公式在 GitHub 筛一轮：

GitHub Search 通用高级语法topic:{目标领域标签，如 ai-agent / llm / rag} stars:>1000 pushed:>{近1个月的日期，如 2026-10-01}

项目健康度硬指标（避坑必看）

最近提交（Last commit）：近 1 个月内必须有实质性代码提交。

Issue 关闭率：Closed / Open 比例大于 1（说明不是只提不修的僵尸仓）。

PR 响应速度：近期 PR 一般在 2 周内有维护者 review 或回复。

发版频率（Release）：保持每月或每季度有正式版本迭代。
